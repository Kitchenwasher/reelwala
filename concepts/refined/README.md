# Life, on Replay — refined motion concept

Selected by user: concept 2. Design images only; no website code created.

## Visual direction
Keep ivory, orange, serif/italic typography and candid event photography. Introduce depth and scroll choreography in the reference's spirit using tools of reel creation: a smartphone and compact gimbal.

## Proposed motion
1. Hero: photo layers drift subtly at different depths around phone/gimbal. Booking CTA remains easy to reach.
2. Scroll-linked rotation: hold composition briefly while phone rotates from rear/three-quarter to front view. The same device should remain physically consistent throughout final animation; generated keyframes are illustrative.
3. Screen expansion: phone screen grows into an immersive event reel, then releases into the page. User initiates audio.
4. Service exploration: carry a floating portrait reel preview alongside Private, Corporate and Cultural service rows; active row turns orange and preview content changes. This adapts the reference's car-over-list interaction.
5. Pinned story: Shoot > Edit > Share. Center imagery advances vertically while title, copy and step indicator update. Include skip control. Three short chapters, not a prolonged scroll lock.
6. Replay gallery: photos follow an elliptical orbit; dragging or arrow controls rotates selection toward the front and enlarges the active reel. Swipe equivalent on mobile.
7. Booking: motion settles for a calm readable lead form. Keep creator recruitment separate.

## Motion limits for implementation later
Static posters and standard gallery on small screens or reduced-motion settings. Avoid forcing long gestures to reach booking. Generated imagery is exploratory, not actual client portfolio work. These are static mockups and a motion storyboard, not playable animation.
